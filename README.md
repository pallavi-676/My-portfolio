## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/pallavi-676/my-portfolio.git
```

Navigate to the project directory:

```bash
cd my-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
